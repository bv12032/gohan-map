# ごはん地図

好きなカレー屋さんやカフェを、地図といっしょに記録するWebアプリ。

- 地図にピンを立てて、★・おすすめメニュー・メモ・写真・行った日を残せる
- 「行きたい」お店も別の色（点線のピン）で残せる
- 今いる場所から近い順にならべかえ
- 記録はその端末のブラウザの中だけに保存（サーバーには送らない）
- スマホとパソコンで同じにしたいときは「設定・バックアップ」でファイルを移す

## 使っているもの
- 地図：Leaflet ＋ OpenStreetMap（© OpenStreetMap contributors）
- 場所さがし：Nominatim（OpenStreetMap）

## iPhoneのホーム画面に置く
Safariで開く →「共有」→「ホーム画面に追加」
